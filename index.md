# rclone-project2-sync

This website provides information about my personal rclone Google Drive synchronization application.

## Purpose

This application is used solely for personal file synchronization between my Linux computer and my own Google Drive using rclone.

The application is not offered as a service to other users.

## Google Drive Access

The application accesses Google Drive only to upload, update, and manage my own project files for backup and synchronization purposes.
