# Privacy Policy

## Application

rclone-project2-sync is a personal application used by its developer to synchronize files between a Linux computer and Google Drive using rclone.

## Google User Data

The application accesses Google Drive data solely for the purpose of uploading, updating, and managing the developer's own project files.

## Data Sharing

Google user data is not sold, shared, or transferred to third parties.

## Data Storage

The application does not operate an independent server or database for storing Google user data. Files are transferred directly between the developer's local computer and Google Drive through rclone.

## Data Use

Google user data is used only for personal file synchronization and backup.

## Contact

For questions regarding this privacy policy, please contact the developer through the GitHub repository associated with this page.
